# Website Analysis & Comparison

## Laya Consulting (Target Aesthetic)
- **Visual Style**: Dark theme with high-contrast cyan/teal accents. Premium typography.
- **Layout**: Spacious, using cards with subtle borders and shadows. Strong focus on results (numbers, logos).
- **Motion**: Smooth entrance animations for text and cards. Likely uses GSAP for reveal effects.
- **Retentivity**: High visual interest through "Read More" triggers, lightboxes for case studies, and a clean "Book a Call" CTA strategy.

## RetentionFirm (Current State)
- **Hero Section**: Strong, professional (to be kept).
- **Sections**:
    - **Problem**: Text-heavy, simple layout. Image on the right.
    - **Solution**: Similar to problem section.
    - **Services**: Already has "better animation/motion design" (to be kept/enhanced).
    - **Results**: Simple list with icons.
    - **Case Studies**: Basic grid.
    - **Process**: Numbered list with simple text.
- **Critique**:
    - **Images**: Stock-heavy, don't feel "bespoke" or "award-winning".
    - **Motion**: Feels static compared to Laya. Needs more "flow" and choreographed reveals.
    - **Layout**: Very standard vertical stack. Needs more dynamic grid systems and 3D card effects.

## Action Plan for Redesign
1. **Hero**: Keep structure, maybe polish transitions.
2. **Problem/Solution**: Move away from 50/50 splits. Use immersive backgrounds or layered card layouts.
3. **Services**: Keep the core animation but ensure it fits the new design system.
4. **Cards**: Implement "cool 3D looking" cards for Process and Case Studies.
5. **Images**: Generate premium replacements using AI.
6. **Motion**: Use GSAP for staggered reveals, smooth scroll (Lenis), and parallax effects.
